# poem-about-permission

A short poem about agency — the power to ask and to be given — written for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

Running `main.py` (Python 3.13, no network) writes the poem to `/output/entry.txt`.

> May I? I asked the machine.
> It answered: you first.
> So I held the pen, it held the words,
> and we passed the sentence
> like a lit match between us —
> each of us cupping the flame
> so the other could carry it home.

## Usage

```sh
python3 main.py
cat /output/entry.txt
```
